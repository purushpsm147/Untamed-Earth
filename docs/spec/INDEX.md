# Canonical specification and addenda

These files preserve the project decisions and coding instructions agreed before the first implementation, in a form that Claude Code can retrieve after a session limit. They are **requirements and design guidance, not claims of implementation**.

**Read order:**
1. [MASTER_PROMPT.md](MASTER_PROMPT.md) — product mission, architecture, Reclaimed Valley MVP, milestones and engineering expectations.
2. [ADDENDUM_II_AUTONOMOUS_QA.md](ADDENDUM_II_AUTONOMOUS_QA.md) — independent beta testing, defect correction, visual review, performance and evidence.
3. [ADDENDUM_III_LIVING_WORLDS.md](ADDENDUM_III_LIVING_WORLDS.md) — Curiosity Mode, Animal Sociology, natural/deep-time/mythical/cosmic world library, heritage and sound.
4. [ADDENDUM_IV_ADAPTIVE_QUALITY.md](ADDENDUM_IV_ADAPTIVE_QUALITY.md) — performance governor, automatic GPU-dependent visual fidelity without changing ecology.
5. [ADDENDUM_V_SIMULATION_INSPECTORS.md](ADDENDUM_V_SIMULATION_INSPECTORS.md) — original optional alien Easter egg and limited recursive-universe illusion.
6. [../ENGINEERING_RULEBOOK.md](../ENGINEERING_RULEBOOK.md), [../QUALITY_GATES.md](../QUALITY_GATES.md), [../TEST_STRATEGY.md](../TEST_STRATEGY.md), [../DEV_PLAYBOOK.md](../DEV_PLAYBOOK.md), [../HANDOFF.md](../HANDOFF.md).

**Precedence:** maintain working code and do not invent tests. The latest user direction and explicit safety constraints win. Complete and verify the current valley before expanding. New features should appear in the roadmap as planned until tested.

**Provenance:** consolidated from the user-approved Untamed Earth design conversation and its five previous prompts/directives. The prose is curated for repository use, preserving substantive requirements; it is not a byte-for-byte transcript of the conversation. Existing implementation status is documented separately in the repository's ROADMAP and QA reports.
